## 完整介绍（粘贴块）

```text
每天一点点坚持，慢慢养成习惯。

日新（Renew）是一款免费、开源、完全离线的习惯追踪应用，帮你把想坚持的事变成每天的自然动作。

【核心功能】
• 习惯打卡：无限创建，连击一天天变长
• 分类整理：颜色与分类，让习惯井井有条
• 习惯笔记：为某一天写下一句话
• 待办清单：今天要做的事随手记
• 专注计时：留一段时间，只做一件事
• 数据统计：连击曲线与统计图表，坚持看得见
• 本地提醒：到点通知，离线照样提醒
• 备份导出：zip / JSON 一键导出，数据随时带走

【隐私承诺】
• 无账号、无注册、无云端
• 无广告、无订阅、无受限功能
• 所有数据仅保存在你的设备上
• 开源透明：代码公开可查（GPLv3）

基于开源项目 Streak 的鸿蒙适配版。
```
