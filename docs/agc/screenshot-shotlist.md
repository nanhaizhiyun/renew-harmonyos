# 真机截图 Shot List（用户拍摄）

> AGC 上架截图由用户在真机上拍摄。本页给出机位、演示数据准备与拍摄要求。

## 设备与规格

- **设备：** 5ZFYD25B20000755（HarmonyOS NEXT，Phase-1 验收同机）
- **规格：** 1320×2760（真机原生分辨率），竖屏，4–5 张，PNG
- **系统语言：** 中文（中文商店素材）；如需英文商店素材，同机位切英文重拍
- **存放：** 截图仅本地保存（如 `D:\ohos-tmp\agc-shots\`），不入库；以 AGC 上传页的尺寸校验为准

## 拍摄前准备

- 建一套干净的演示数据：5–7 个习惯（不同颜色／分类），连击 10+ 天更有说服力；加几条待办；不要放任何真实个人信息
- 关闭开发者选项与悬浮窗提示；状态栏电量充足、信号正常再截
- 确认桌面名称显示为「不止习惯」、图标为当前版本（Task 4 改版后效果）

## Shot list

| # | 画面 | 要点 |
|---|---|---|
| 1 | 习惯列表（应用主页） | 5–7 个带连击的习惯，颜色分类清晰；第一张图最重要，直接决定转化 |
| 2 | 习惯详情 + 统计 | 选一个连击长的习惯，展示统计图表／打卡热力，体现"坚持看得见" |
| 3 | 待办清单 | 几条待办、部分已勾选，展示随手记的轻量感 |
| 4 | 专注计时 | 专注页进行中的界面，倒计时清晰可见 |
| 5（可选） | 备份／数据页 或 提醒编辑页 | 展示"你的数据由你掌控"（导出入口）或本地提醒设置，呼应隐私与提醒卖点 |

## 拍摄操作

- 真机截屏：音量下键 + 电源键（或控制中心截屏开关）；不用第三方工具，避免水印
- 拍完检查：无个人真实信息、无水印、界面干净、连击数字醒目

## 上传提示

- 按清单顺序上传，第 1 张放习惯列表主页
- 若 AGC 校验尺寸被拒，先尝试原图，再尝试等比缩放（以 AGC 上传页要求为准）
